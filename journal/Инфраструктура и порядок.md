### 25–26.10 · Работа автора с другим ИИ, технические итоги, не вошедшие в строку «последний…

> [!abstract] Что делали
> Работа автора с другим ИИ (Mercury 3 в OpenCode), технические итоги, не вошедшие в строку «последний патч». 1) Перенос на C++ (просьба автора «органы на C++»): проверка единиц судьи по шагам (units.cpp → units.dll: stem, unit, bracket, с откатом на Python) и датчик сомнения (probe.cpp → probe.dll: 2048 весов + сигмоида); найден и исправлен баг utf8_yo_to_e (ё путалась с б — отсюда «руел»). perception.py (~200 строк регулярных выражений) оставлен на Python. 2) Видеопамять: мозг 5.0 ГБ + голос Qwen3-TTS 1.7B 4.3 ГБ = 9.3 > 8 — вместе не помещаются; «встроить голос в мозг» — тупик (другая архитектура, нужен переобученный Omni-подобный мозг); пути: часть слоёв голоса на процессор, 8/4 бит. Готового GGUF для нашего русского персонажа-образца нет — план конвертации через qwen3-tts.cpp (не начат). 3) Голос: синтез рассказа всеми 9 голосами, идея микро-модуляции F0; обучение v2 (LoRA r16, 3 эпохи, 20 рассказов, выбранных автором). 4) Внешние учителя: OrcaRouter/DeepSeek V4.1 Flash (лимит исчерпан), Groq gpt-oss-120b, прокси orcaproxy (порт 8765), external_teacher.py; план дообучения (QLoRA, DPO).

> [!info] Результат
> C++ совпадает с Python 30/30 (stem, unit), bracket идентичен; датчик на 935 скрытых состояниях разделяет верные/неверные (0.283 / 0.146). Скорость (20 000 вызовов): stem 1.2×, unit 1.8×, bracket 0.6× (медленнее из-за ctypes), probe 3.4× — в секундах выигрыша почти нет: в живом сервере датчик уже был на C++. Голос v2 подключён (откат — voice_config.json.before-v2).

> [!tip] Вывод
> C++ дал не скорость, а чистоту: units/probe без torch и Python. Узкое место — видеопамять, а не код. Дообучение через внешних учителей автор признал «фигнёй» (27.10) — OpenCode убран из Нейры.

> [!info] Результат

ВНИМАНИЕ (проверено 27.10): neira_chat_cli.py, neira_behavior.py, neira_behavior_rules.json и REPO_PLAN.md исчезли из neira-tools и не попали в git — вероятно, удалены вместе с OpenCode; восстанавливаемы из opencode.db так же, как C++-версии.
